#### 인프라 아키텍처
![AI Hackathon](./AI%20Hackathon.png)

1. 제품 키 입력(9999) - 일치여부만
    - 키가 일치해야 회원가입/로그인 입장 가능
2. 회원가입, 로그인
3. 자세교정(OpenCV, MediaPipe) 🌟
    1. 초기 자세 찍기 전에 올바른 자세 가이드 먼저 제시 - 하드코딩
    2. 처음 초기 자세 기준으로 사용자 자세 측정
        1. 실제 사용할 자세 기준으로 한 컷
            - 사진을 찍으면 해당 사진의 스켈레톤 좌표만 저장
        2. 실루엣으로 유저 위치 고정
        3. 좌대각/우대각/정면(3가지)중 하나를 선택해서 초기 설정
    3. 자세가 안좋으면 팝업으로 자세 안좋다고 보여줌
        1. 그래도 안고쳐지면 경고(개zl랄맞게)
        2. 환경 설정에서 얼마나 엄격하게 경고할지 설정 가능
    4. 환경 가이드 제시(바른자세 알려주는 그림)
    5. 현재 자세를 개선할만한 스트레칭 🌟
        1. 50-60분마다 스트레칭 제안(설정 가능)
            - 앉아서 하는 스트레칭만 제공
            - 서서 하는 스트레칭은 로드맵
        2. 스트레칭 자세 보여주기
        3. 스트레칭 자세 교정 (카메라vs교본)
            1. 실루엣으로 유저 위치 고정
            2. 실시간 사용자 자세와 스트레칭 자세 비교
    6. 일시정지 기능
4. 자세 진단 리포트 제공 🌟
    1. 그래프 제공?
    2. 시간당 평균 자세 유지 시간
    3. 일일 레포트 제공
        1. 시간대 별로 그래프 나타내서 시각화해서 보여주기(1시간 단위 갱신)
        2. 사용자가 올바른 자세를 유지했냐에 따라서 아바타의 모습 변화 제공(그래프와 함께)
        3. 레포트 메인화면에서 달력-사용한 날짜는 색 다르게 표시→누르면 일일 레포트
            1. 많이 사용한 날은 색 더 진하게
    4. 월별 등 추이(저희 앱을 쓴 시간이 이만큼 늘어서 자세가 이만큼 좋아졌다)\
        1. llm(아바타)이 코멘트(짚을만한 추이, 주목할만한 데이터, 해석)
5. 아바타 부여해서 자신의 자세 추이에 따라 아바타의 자세 바뀜 🌟
    1. 아바타가 llm 챗봇으로 말을 걸기?
6. 모니터링 화면
    1. 카메라
    2. 아바타
    3. 그래프
